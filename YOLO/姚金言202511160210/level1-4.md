# 工程实践题

## Level 1：配置YOLO环境	

### 1.安装并配置anaconda

### 2.配置conda，创建虚拟环境

打开终端，创建一个新的环境，比如``conda create --name yolov8 python=3.9``，然后激活这个环境``conda activate yolov8``, 这样我们就进入了这个独立环境。

之后我们的操作都需要在这个独立环境中完成。

**在这一步中我学到的：**

- 在终端中，鼠标是失效的
- 执行命令后不能撤销
- 按上键可以回到上一条命令
- ctrl＋c可以暂停
- 所有安装都需要在独立环境中进行

### 3.安装PyTorch 

在安装配置好conda后，我们需要安装一些依赖包。根据我的电脑配置，我选择安装GPU版本。首先选择安装对应版本的cuda和cuDNN，接着在官网安装对应的PyTorch。在这个过程中，ultralytics也完成了安装。

### 4.检查环境是否配置成功

首先一定不要忘记激活虚拟环境

在终端中运行预测命令``yolo predict model=yolov8n.pt source='https://ultralytics.com/images/bus.jpg'``,命令运行完成后，会创建一个名为predict的文件夹，在这个文件夹中我们可以找到被方框和标签成功标记的图片。如果这个过程顺利完成就说明我们的yolo环境配置成功。

我们也可以使用yolo自带的coco128数据集进行测试

>什么是 coco128 数据集？
>
>- **官方“迷你”数据集**：它是著名的COCO数据集的前128张图片组成的一个微型样本。
>
>- **内置便利性**：YOLOv8的ultralytics库内置了对它的支持。您不需要手动下载、解压或配置.yaml文件。
>
>- **用途**：它专门用于快速的功能测试、调试和教学演示。因为数据集很小，所以训练过程会非常快。

激活环境后，将终端路径改为我们的yolo文件夹，运行``yolo train model=yolov8n.pt data=coco128.yaml epochs=10 imgsz=640``命令进行训练，训练结束后，我们可以在train文件夹中找到训练结果。此次运行成功也可以说明yolo环境配置无误。

**在这一步中我学到的：**

- 查询当前虚拟环境下安装的所有包：
  - 使用``pip list``命令可以查看通过pip安装的包
  - 如果想要查看全部的，可以用``conda list``命令

- 更改终端路径：
  - 进入下一级文件夹：``cd 文件夹名称``
  - 返回上一级文件夹：``cd ..``
  - 进入任意文件夹：只要知道完整路径，我们就可以跳转到任意文件夹，使用``cd 完整路径``
  - 切换盘符：如果想从C盘切换到D盘，可以直接输入``D:``再回车

## Level 2：下载和标注数据集

下载完数据集之后，我们需要编写python脚本，批量解析图片文件名，生成yolo格式的.txt标签文件。

首先我们需要安装opencv，在虚拟环境中运行``pip install opencv-python``命令即可完成安装。

接着新建一个labels文件夹，用来存放新生成的标签文件。将这个文件夹放置在与CCPD文件夹同级的目录下。

然后我将ai提供的代码保存为了一个名为ccpd_parser.py的文件并按照提示依次配置路径、安装依赖、运行脚本、检查结果。

 **配置路径**

>- 打开 `ccpd_parser.py` 文件,找到底部的 `if __name__ == '__main__':` 部分。
>- 修改 `SOURCE_IMAGES_DIR` 变量，将其值设为您存放CCPD图片的文件夹的**绝对路径**。
>- 修改 `OUTPUT_LABELS_DIR` 变量，将其值设为您想要存放生成的 `.txt` 标签的文件夹的**绝对路径**。

**安装依赖**

在*Anaconda Prompt*中激活虚拟环境并运行``pip install tqdm``命令，安装tqdm。

我们可以通过前文提到的``pip list``检查是否安装成功。

**运行脚本**

在终端中激活环境，并进入 ccpd_parser.py 文件所在的目录。运行命令即可。

**检查结果**

运行完成后，我们会在我们新建的labels文件夹中看到大量.txt文件，随即打开一个后我们会看到一行符合yolo格式是数据，比如我当时的数据是0 0.488194 0.456034 0.356944 0.075862。

这说明我们的ccpd_parser.py 脚本已经成功运行，并且正确地完成了它的所有工作。

## Level 3：划分数据集，配置并训练模型

### 1.划分为训练集（train）和验证集（val）

我们需要将所有图片和标签文件，按8:2或9:1的比例，随机划分为train和va1两个集合，并分别放入对应的
images 和labels文件夹。这里我运用了ai给我的python脚本。

将该脚本保存为split_dataset.py并保存在项目根目录下，重复我们上一步配置路径的过程，接着在终端中运行``python split_dataset.py``命令，注意一定要将终端路径改到项目目录。

现在，我们就已经拥有了一个可以随时用于YOLOv8训练的数据集了。

**在这一步中我学到的：**

- 怎样将代码保存为一个文件：（我使用的是Windous自带的记事本）

  - 在空白记事本中粘贴需要保存的代码
  - 将文件另存到相应位置（比如在本题目中，我们创建的yolo文件夹）
  - 在“保存类型”中选择“所有文件”，防止记事本自动将其变为python无法识别的txt格式
  - 必须包含 .py 后缀，例如ccpd_parser.py

- 绝对路径与相对路径

  >可以把“**绝对路径**”想象成一个文件或文件夹在您电脑上的**完整家庭住址**。这个地址必须从“国家”（比如 D: 盘）开始，一直精确到“门牌号”（具体的文件夹）。
  >
  >**绝对路径（正确示例）**: D:\My_License_Plate_Project\images
  >
  >这个路径非常明确，无论您从哪里运行脚本，电脑都知道要去唯一的这个地方找东西。
  >
  >**相对路径（本次配置中应避免）**: images
  >
  >这就好比说“隔壁那家”。只有当您正好站在正确的“邻居家”旁边时，它才有效。为了避免混淆，我们在配置文件里必须用绝对路径。

### 2.创建.yaml文件

我们将基于上一步的数据集结构来编写这个.yaml文件。

首先在项目根目录中新建一个名为license_plate.yaml的文本文档。（此处要确保文件的扩展名是.yaml 而不是 .yaml.txt）

将aii提供的文件内容粘贴进去之后，我们就可以用这个文件来启动训练了。

运用GPU训练，在虚拟环境中运行``yolo train model=yolov8n.pt data="D:\yolo\yolo\ultralytics\datasets\mydata\mydata.yaml" epochs=100 imgsz=640 batch=16 device=0``命令，开始训练。

*此处省略漫长的两个小时*

## Level 4：使用训练好的模型进行推理

### 1.**定位并确认模型文件**

找到我们在level3好不容易训练完成的结果，我们将看到best.pt 和 last.pt这两个文件，这两个文件非常重要。

> **best.pt**: 这是您**必须使用**的模型。它是在训练过程中，在验证集上表现出最佳性能时保存下来的版本。**last.pt**: 这是训练到最后一个 epoch（轮次）时保存的模型，不一定是性能最好的。

### 2.**准备推理代码**

在项目根目录下，创建一个新的 Python 文件，例如 inference.py。

在文件的开头写入ai提供的代码``from ultralytics import YOLO
import cv2 # 如果要进行实时摄像头推理，建议导入OpenCV``

接下来我们就可以分别针对照片、视频、摄像头进行推理。

**对照片和视频推理**

根据ai的指导在我们创建的新文件中添加相应的代码，注意需要将路径改为自己文件的真实路径（如果推理照片的话，将其替换为best.pt文件的真实路径）

在终端中运行脚本，运行完毕后，我们将会看到一个新的文件夹，推理的结果都在里面。

**对摄像头进行实时推理**

在电脑有可用摄像头的前提下，将代码中source的参数设置成（），使用电脑默认摄像头。

运行后电脑弹出窗口，显示摄像头画面。

关闭系统只需按下q键。

**在这一步中我学到的：**

- 创建一个新的python文件
  - 打开相应文件夹，确保文件被创建在正确位置
  - “项目”面板中新建文件
  - 为新文件命名时注意要以.py结尾

-  Python 的字符串中的反斜杠

  - > 在 Python 的字符串中，反斜杠 \ 是一个特殊字符，叫做“转义字符”。它会和后面的字母组合起来表示特殊含义，比如 \n 表示换行，\t 表示制表符。

  - 最方便的解决方法是在字符串的引号前面加一个r，这个 r 告诉 Python，这个字符串里的所有内容都是原始字符，不需要转义。

**在这一步中遇到的问题**：

我在inference.py 文件中写下导入所需库的代码后出现报错，import cv2 下方出现了一条红色的波浪线和一个感叹号灯泡图标。这说明在我当前的 Python 环境中找不到一个叫做 cv2的库。而在此之前，我已经安装了 OpenCV。这说明pycharm当前使用的 Python 环境和我安装库的终端环境不是同一个。

遇到这种情况，需要我们为 PyCharm 设置正确的 Python 解释器

在菜单栏中的“文件”中选择“设置”，点击“添加”，在弹出的“添加 Python 解释器”窗口中，从左侧列表中选择 Conda 环境，选择“现有环境”，pycharm会自动选中我的yolov8环境。确定无误后点击“应用”。这时之前的报错就消失了。
